## 🗂 What I work on

**🧊 Lakehouse & data engineering**
- Maintenance and cleanup tooling for Apache Iceberg tables (snapshots, orphan
  files, compaction)
- Builder frameworks and templates for Spark pipelines on Kubernetes and AWS
  Glue
- Dataset diffing and reconciliation reports across bronze / silver / gold
  layers
- Parquet inspection utilities and lightweight data-viewer apps

**⚙️  Serverless & job orchestration**
- Retry and control APIs around AWS Glue jobs
- Serverless alerting and event-driven workflows on AWS Lambda
- Job scheduling and monitoring across hybrid AWS / on-prem stacks
- Streaming and event-driven integration with Kafka and Azure Event Hubs

**Cloud, DevOps & platform**
- Ephemeral GitHub Actions runners on AKS — ARC + Karpenter, pinned images,
  Azure Workload Identity, true scale-to-zero
- Azure control-plane automation: scheduled VM start/stop, cost-control,
  landing-zone friendly, with a small Streamlit UI on top
- Reusable CI/CD templates (Azure Pipelines, GitHub Actions) and container
  images
- Backend and platform services built with Java, Spring Boot, .NET and Python
- SQL / PostgreSQL / NoSQL-backed applications plus low-code and no-code
  delivery where it makes sense
